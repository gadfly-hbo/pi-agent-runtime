## 接口与验证接缝

此前已确认的测试接缝是共享 SDK 的公共执行接口及宿主接点，不测试 Pi 私有实现。首版提供单次结构化变换、有界串行工具循环、累计预算、逐次授权、独立超时取消、脱敏审计及合成模型录制/回放。模型 transport 是外部系统接缝，测试注入合成响应，但循环与工具参数验证使用安装的真实 Pi 0.86.1。

宿主持有业务任务、语义、工具、授权和正式成果的权威。共享层只提供运行机制。工具返回 pending 或模型说完成不构成业务批准。只接受宿主显式配置，默认不发现认证文件、工具、skills、会话或环境密钥；无自动 fallback、retry、compaction、恢复执行、Shell 或 MCP 扫描。

首版不引入数据库、持久化迁移或业务 schema。AuditSink 与 BudgetStore 是宿主接点；内存实现仅供离线/同进程使用，不宣称崩溃恢复。跨进程原子性和持久存储须由宿主提供并运行相同接入检查。

## 需求与验收

| ID | 行为 |
|---|---|
| R01 | 无工具 worker 单次请求，JSON 解析后经宿主 validator；不合法输出拒绝 |
| R02 | Pi 驱动模型→合法工具→模型；未知工具和不合法参数不执行 |
| R03 | 模型请求及工具副作用前复查宿主授权；取消/撤销后不发布成功结果 |
| R04 | 同任务累计模型、工具、输出 token 和资源额度；请求不重置预算；并发准入原子 |
| R05 | 独立墙钟定时器；取消拒绝新操作与迟到结果；未知执行保留占用，不自动退款/重放 |
| R06 | 审计失败 fail-closed；审计不保存 prompt、工具参数/结果或凭据原文；UI 观察者不是审计门 |
| R07 | 明确模型身份、输入版本引用、运行用量和停止原因；Pi 类型不出公共接口 |
| R08 | 合成模型 record/replay 严格匹配请求；无真实副作用重放；发布入口可独立消费 |
| R09 | 核心两包精确 0.86.1，lockfile 锁传递依赖；无 coding-agent；npm ci 可重现 |
