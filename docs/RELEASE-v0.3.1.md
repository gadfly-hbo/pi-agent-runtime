# SDK0.3.1 同任务用途兼容候选

2026-10-09用户明确授权共享SDK补齐同任务固定分析/报告用途。精确Pi0.86.1不变，原0.3.0冻结包不变。

新增RuntimeOptions.purposes与BaseRequest.purpose。每个PurposeConfig固定模式、主备模型、工具定义和可选运行策略。每次执行显式选用途，仍通过同一SDK/Pi循环和权限、计量、安全审计、取消及迟到护栏。整个计划及限额共同形成不可变任务身份，改未使用用途也不能继续旧账户。工具执行器使用创建时宿主能力，不能请求替换。函数和凭据不序列化，正确性仍由可信宿主及逐效果授权控制。

没有purposes的旧接口和哈希保持不变。旧任务迁移须由产品对账消耗与UNKNOWN；同taskId重建Runtime不会重置BudgetStore。用途切换不是失败重试，不扩产品一次额外请求上限。

验收：真实公共SDK接口离线工具分析两轮→无工具报告，预算累计及耗尽拒绝；负例含未声明用途、错误模式/策略、改变计划和工具、输入修改。保留原取消/迟到/审计/主备/协议回归。真实Provider、产品接入和独立审查尚待完成。
