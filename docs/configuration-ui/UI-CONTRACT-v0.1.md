# 模型配置 UI 原型合同 v0.1（待确认）

2026-10-07；与 PROPOSAL-v0.1.md 一起整体确认。用户截图仅借鉴简洁 Provider 卡片/字段结构，不复制供应商、模型 ID 或能力承诺。

入口：`prototypes/model-settings-v0.1/index.html`。页面刷新重置；不保存到 localStorage、文件、数据库；没有 Provider 请求。默认空态，可载入明确标注的合成演示。凭据原型为“模拟设置/清除”，不接受真实 Key。

| ID | 可观察验收 |
| --- | --- |
| UI-01 | 默认无配置，无主备，不允许生效；显示补齐方式；演示数据只在用户主动载入后出现 |
| UI-02 | 新增/编辑 Provider 名称、Base URL、API 协议；仅两种支持协议，Responses 不可选；使用无网络的模拟凭据状态 |
| UI-03 | 新增/编辑模型 ID、名称、上下文上限、声明工具能力；非法值/同 Provider 重复模型 ID 在提交时被拒绝 |
| UI-04 | 一个主模型、至少一个备用；备用有序且不重复，不能与主模型重复；上/下移可用键盘操作 |
| UI-05 | Provider/模型启用不是主备选择；已生效引用的对象不能直接禁用/删除；先重配生效再操作 |
| UI-06 | 草稿可不完整；保存草稿不生效；生效失败保留上次生效版本；未生效更改有标记；放弃后回到生效快照 |
| UI-07 | 单次调用/工具 Agent 的用途切换用于演示能力匹配；工具用途下不具备声明工具能力的主备都不得生效；连通性不当作工具能力证明 |
| UI-08 | “模拟检查”明确不联网；不设置真实通过状态；编辑相关配置令模拟观察失效 |
| UI-09 | 320px 窄屏不横向溢出；暗色保留层级；输入有标签，弹窗 ESC/关闭可用，反馈有 live region；200% 放大重排 |
| UI-10 | 页面不含真实 Key、不访问远端资源、不通过浏览器直接请求 Provider；只实现原型内存态，刷新重置 |

正式 UI 将把原型的内存操作换成注入宿主回调，并补齐载入失败、保存失败/版本冲突、真实检查进行中/取消/失败状态。原型有同步本地校验，没有网络失败模拟；不声称这些正式状态已经完成。

生效并不等于任务运行。报告、工具列表、业务授权和数据出境提醒由产品流程负责，不在此设置页重复建设。
