# 简化配置原型 v0.2

本轮按用户 2026-10-07 提供的三张参考图修正，替代 v0.1 的 UI 方案；v0.1 源文件/截图/失败及验证历史原样保留，不覆盖旧证据。

设计原则：Provider 直接展示可编辑字段；模型单行显示 ID、上下文标签、图标和开关；次要操作收进省略号；主备只保留必要选择；正常态不展示内部运行机制；一个“保存”，后台仍应校验，不让简化 UI 变成降低安全约束。

删除界面上的 Worker/工具 Agent 用途选择、版本/草稿/生效信息、预算/授权说明、品牌顶栏和多按钮保存流程。主备放在 Provider 下方。模型弹窗按第三张参考图保留模型 ID、上下文窗口、最大输出 Token；智能配置未接资料源，禁用并解释，不假装自动识别。

API Key 是只读固定虚构值，眼睛图标仅切换该虚构值显示，不输入、不保存真实密钥。真实密钥由未来宿主接入。Responses 仍未实现，选项禁用。示例中的名称/地址/模型 ID 借鉴截图，所有参数仅为展示示例，未证实实际供应商支持；不是默认主备配置。默认空态，主动“查看示例”后才载入。

本原型没有 fallback 执行、额度识别、Provider 调用、持久化或 Runtime 集成。最大输出 Token 是单次生成限制，不是供应商额度或任务总预算。该字段及智能配置的正式共享合同尚未批准，不在本轮写入 SDK。

启动预览：

    python3 -m http.server 48174 --bind 127.0.0.1 --directory prototypes/model-settings-v0.2

仍仅在内存中保存；刷新清空。正式 UI/配置合同待用户确认，本轮只修原型，不要求重新讨论未受影响的架构。
